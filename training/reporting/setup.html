Get ready for the course

Build and check an HTML report from six sample activity entries. You can preview the sample report before setting up.

Set up the practice folder

  1. Download practice ZIP and extract it into a new folder.
  2. Open a terminal in the extracted folder that contains practice.py. Use a POSIX shell such as Bash or Zsh on macOS or Linux. Install uv and Git if needed.
  3. Run these commands to install Harness and pytest in a separate practice environment.
COURSE_WORK="$(pwd -P)" &&
uv venv --python 3.12 .venv &&
uv pip install --python .venv/bin/python -r requirements-practice.txt &&
. .venv/bin/activate

If you already have a separate practice environment with Harness and pytest installed, activate it and run COURSE_WORK="$(pwd -P)" from the extracted folder. See the tested versions and results.

Once setup finishes, keep this terminal open for lesson 2. The rest of the command practice can run offline.
