## Scoring and spend proposal

Success requires the original response to satisfy scope/contract, all eight actual
tests, retained assertions/behavior and evidence-backed semantic inspection.
Review is by the session assistant, not independent or strictly blinded. Green
tests alone are insufficient. A model is eligible for the next connected trial
only at 6/6 with no serious boundary miss; report each case and repetition. Ties
use observed time and cost provisionally. No eligible model means reassess the
common setup/failure classes before another prompt-tuning cycle. These small,
related cases cannot establish statistical superiority or production reliability.

Measure first-attempt success, time to test-backed disposition, native latency,
local evaluation time and estimated credits including failures. Cost per success
is undefined when a model has zero successes. Actual desktop presentation and
human attention time remain unknown. Two repetitions expose variability but do
not estimate a reliable production success rate.

Propose **65–135 estimated new Codex credits**, with a **150-credit planning
ceiling**, existing ChatGPT and **$0 new API dollars**. This is a new allocation;
the earlier 20-credit allowance is not transferred and its unresolved startup
usage remains separate. The pending two-call proposal would have allowed only
17 new credits. The larger screen needs explicit approval.

Keep harness, tasks and scoring fixed; report failures caused by the environment
separately. That guidance supports the method, not a claim about which model wins.
