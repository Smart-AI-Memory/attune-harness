and reference text but omitted the actual document's link and the host checks
given to the assessor. Sol therefore marked legitimate link/path/hash statements
as inventions (a01 and a07). The three controls still passed: they checked simple
grading behavior, not completeness of each real item's evidence. Those initial
grades cannot support acceptance. This is an experiment-controller defect, not
evidence that the assessment models invented the omitted inputs.
