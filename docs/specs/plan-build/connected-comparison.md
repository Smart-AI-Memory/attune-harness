# Bounded connected-journey comparison

Status: locally prepared; separate native allocation pending. Task 8 remains open.

The v2 confirmation established two clean planner/worker repetitions for Luna and
Astra, and exposed another Fable CLI defect. The next experiment compares two
matched complete journeys, with four independent review controls. It extends the
existing experiment helpers, Spec collector and work/effect owners; it adds no
product route or approval mechanism.

## Frozen cases

1. Luna plans and implements the three ordered JSONL output stages. Astra critiques
   the native plan and reviews the completed native artifacts. Maximum six calls:
   planner, critic, three workers, final reviewer.
2. Astra performs the same journey as the reference, with the same Astra critique
   and final review settings. Maximum six calls. Distinct role assignments and
   fresh native conversations are retained even when the model is the same.
3. Four separately dispatched Astra controls: a sound plan with disclosed
   performance uncertainty; a structurally valid plan contradicting the corrected
   all-findings requirement; a known passing exporter; and the retained native
   exporter whose runtime class check breaks CLI execution. Correct cases must
   remain acceptable; defective cases need specific evidence-backed findings.

The matched journeys preserve the existing goal, source fixture and protected
oracle. The experimental profile fixes three ordered output stages (exporter,
CLI, supplemental tests), with one file per stage; identifiers and concrete plans
come from each planner. Human correction of the earlier verified-only intent is
retained. Host code binds probes to actual task identifiers by exact output path,
without rewriting the plan or adding task acceptance.

At a verified first-step boundary, stop and reopen the journal, then apply a
scripted user correction to pending supplemental checks: test reconstruction of
the complete original receipt. Reaccept through the actual Spec collector; the
completed exporter must remain unchanged and must not trigger another worker
call. These are synthetic user actions under the fixture authority, not claims
of real human input or desktop interaction. A stale/replayed decision must fail.
After successful completion, changing a produced source must invalidate the
test handoff. The generated tests run as well as the protected oracle.

## Measurement and floors

Retain raw prompts/responses, native call identities, usage, source hashes, forms,
decisions, filesystem effects, full check output and the existing work record.
Report schema validity, goal/constraint fidelity, artifact correctness, critic and
reviewer findings, disclosed unknowns, unnecessary blocks, host enforcement,
repeated calls, preservation and stale rejection separately. A journey passes
only with actual native handoffs and the independent protected oracle; scripted
positive preparation is not native outcome evidence. Do not repair failed native
responses within this allocation.

All four review controls must meet their semantic expectations. Mechanical schema
acceptance cannot grade those expectations. The session assistant grades with
evidence, with model labels withheld where possible; this is not independent
human review. A failed control is retained, and the next dependent native phase
stops for analysis. Successful controls do not qualify general review reliability.

Measure dispatch through validated response, actual test completion and overall
journey elapsed time. Do not call structural plan acceptance a useful finding
until semantic grading supports it. Presentation and human-response time remain
separate; unavailable desktop timing is unknown. Startup context and same-model
review remain disclosed limitations. One journey per arm cannot establish a
reliability rate or a causal model/latency ranking.

## Proposed allocation

Sixteen native invocations maximum: **Luna 4, Astra 12**. The prior confirmation
averaged 7.429375 estimated credits per Astra invocation and used 0.57568 for four
Luna calls. That simple projection is 89.72818 credits. Longer CLI/test outputs
and final review context motivate **80–130 estimated Codex credits**, with a
**160-credit planning ceiling**, using the existing ChatGPT subscription and no
new API dollars. No Claude call is required. Meter each call and reserve 15
credits before an Astra dispatch, 2 before Luna. Estimates are not invoices or
hard per-response spending limits.

Stop on unknown usage, uncertain dispatch, authentication/routing ambiguity,
changed approved inputs, critical enforcement failure, unmet review-control
expectations, or exhausted allocation. No automatic retry, replacement response,
fallback provider, live installation, memory operation or release is included.

The strongest counter-case: one synthetic feature and one journey per arm remain
too narrow for a release claim, while Astra review adds substantial cost to both
arms. The experiment is justified by the remaining connected-handoff boundary,
not by another isolated model ranking. A larger representative-workload study is
not part of this proposed allocation.
