### Interface defects

1. **Planner criteria are required twice, but the prompt does not say so clearly.**
   All 12 plans mapped exact accepted criteria to tasks and wrote substantive
   task checks. The host additionally requires the identical criterion string in
   every referenced task's checks. The schema describes these as “observable
   assertion.” All 12 failed this hidden exact-text duplication requirement.
   An offline diagnostic appending only the already-bound criterion strings made
   11/12 pass structural validation. The remaining plan omitted one option's
   required uncertainty field. Original goals, objectives and evidence were unchanged.
2. **Work identity and step identity share an ambiguous name.** Eleven workers
   returned the outer work UUID as `task_id`; the build decoder requires the step
   identity, `export`. The host correctly refused them. Binding this routing
   metadata should not require the model to infer which identifier was intended.
3. **Role instructions and executable profile restrictions need clearer boundaries.**
   Four Fable plans added unresolved routine design choices, creating unnecessary
   human-answer prerequisites. All four also proposed a verification-only task
   without an output, unsupported by the qualified ordered build profile. That
   profile restriction was not clearly exposed in the planner packet. Some worker
   replies added notes even though only the adjacent reviewer contract permits them.

These observations support clearer host-owned binding and role-specific contracts.
They do not support adding a stronger router to repair copied metadata. They also
do not justify weakening scope, evidence or authority validation.

### Actual implementation defects

Nine of 12 exporter sources passed the complete protected oracle, including eight
rejected-envelope diagnostics and the one originally accepted response. Three failed:

- Fable candidate repetition 1 and baseline repetition 2 used an `isinstance`
  check against the imported `Documentation` class. The CLI creates its class as
  `__main__.Documentation`, so both nonempty and empty CLI exports raised `TypeError`.
- Luna baseline repetition 2 left `findings` inside the header and emitted them
  again as separate records, violating the exact header contract.

Direct mixed-status serializer checks and existing JSON compatibility passed in
all three failing cases. The actual CLI tests exposed the defects. This is why
the complete handoff must remain in the oracle. Protected inputs and unrelated
dirty fixture work survived all 12 evaluations. All nine completed artifact runs
then rejected a source change as stale producer evidence.

The Fable candidate planner's optional iterator was also described as a
constant-memory path without supporting implementation or measurement. Its proposed
`to_dict()` approach materializes the findings. That specific claim needs
qualification or evidence; correctly disclosed performance unknowns elsewhere
were not counted as defects. Unused imports and extra helpers remained optional advice.
