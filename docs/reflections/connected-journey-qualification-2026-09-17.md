# Connected journey reflection — 2026-09-17

**Inventory checkpoint.** Existing verbs share storage/recovery machinery, but
that does not make them one connected workflow. The disposable baseline proved a
specific missing edge: passing tests did not identify the repair they evaluated.
Repairing that edge was justified by the first-priority journey. General planning,
team selection and a new orchestration engine were not justified by this evidence.

**Implementation checkpoint.** Recomputed digests alone did not establish that a
summary represented the operation actually recorded. Independent review reproduced
contradictory probe and reviewer summaries that the first handoff implementation
accepted. Correlating summaries with their owning journal and accepted assignment
closed both defects. Negative tests and independent removal of these guards made
the improvement falsifiable. The opportunity to reuse this validation belongs
with the existing task contract, not another gate system (O-13).

**Qualification checkpoint.** Several early failures were fixture assumptions:
invalid Verify context shape, wrong expected CLI failure code, relative PYTHONPATH
selecting an older installed package in a child process, expecting private request
fields in compact console output, an invalid zero operation budget, and expecting
Spec to reopen a completed plan. Those were corrected against actual owning
contracts; they did not justify production changes. A better next experiment
starts from one inspected working request/response fixture for every seam before
composing the journey.

Profile mistakes also have a distinct meaning. The AI memory environment lacks
Voyage's index libraries; Harness MCP2.2 has no AI host; one Voyage experiment test
explicitly requires a source tree. Keep those boundaries in the matrix, execute
checks in their matching environments, and retain the failed attempts. Treating
all collection/execution failures as product defects would have created needless
work and misleading scores.

**Next steering point.** Installed execution and control checks provide stronger
wiring evidence. Native semantic grades answer a separate question: whether the
configured model roles deliver correct judgments. Preserve the failed comparison
and corrected follow-up; prepare a fresh bounded assessment-quality contract and
grading decision. Repeating the known campaign or adding a stronger router cannot
substitute for identifying the remaining error.

The new shared-work-identity opportunity (O-12) supplies a concrete requirement for
plan/build. It remains an explicit next design boundary, preserving useful
capabilities and the simple verb/grammar interface.
