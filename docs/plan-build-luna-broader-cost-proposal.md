# Broader Luna validation — cost proposal

September 18, 2026. Patrick asked what it would cost to test the recommendation
to carry Luna forward. **Estimate only; cases are not prepared and no new native
allocation is approved or started.** The completed routing pilot remains closed.

Recommend a bounded Luna-only validation: **20 distinct realistic repair cases,
two original attempts each, for 40 calls**. Include larger modules and unrelated
behavior that must survive, rather than repeating the eight short synthetic
cases. The final cases, preservation checks and stopping rule must be prepared
and frozen before native execution. This is a proposed scope, not an already
qualified packet or a population-reliability claim.

## Estimate

- **10–20 new estimated Luna worker credits**.
- **30-credit planning ceiling**, separate from every closed allocation. This is
  a planning allowance, not a guaranteed account charge cap.
- Existing Codex ChatGPT authentication and **zero new API-dollar allocation**.
- Astra semantic review in the active session; its ordinary session usage is
  additional and excluded from the worker estimate.
- No Sol control calls, separately paid grader, automatic retry or purchase/reset
  is included. A subsequent comparison or native final-review trial would need
  its own scope and estimate.

The earlier, larger 27-call Luna sample cost 4.414375 credits: **0.163495 per
call on average**, with a maximum of **0.304120**. Forty calls at that mean would
cost 6.539815; forty at that observed maximum would cost 12.164800. These are
historical projections, not upper bounds for new cases.

The proposed 10–20 range allows larger inputs/outputs and less favorable caching.
Using the same September 18 frozen Standard Luna rates as the completed trial
(5 input and 30 output credits per million tokens), uncached scenarios of
30,000 input plus 3,500 output tokens cost 0.255 credits/call, or 10.20 for forty;
50,000 input plus 8,000 output tokens cost 0.49/call, or 19.60 for forty. The
30-credit planning ceiling adds margin. Final preparation should revisit these
assumptions if actual case sizes require a materially different allowance.

The completed narrow pilot cost **35.370918 total worker credits**, including
16 Sol calls. Its Luna-only component was **1.744678** for sixteen calls. That
completed spend is separate from this proposed next test; the 30-credit ceiling
is entirely new, not transferred unused headroom.

This proposed validation supports or falsifies the intended Luna scope. It does
not by itself qualify a universal default, a Luna-to-Sol fallback, production
routing, native final review or Task 8 completion. The earlier Luna preservation
failure that passed eight tests remains the reason to include realistic
preservation checks and session semantic review.
