# Disposable mixed-queue memory sorter experiment

2026-09-16. Patrick explicitly authorized the next proposed experiment: Luna
sorts a mixed queue and completes routine work in one pass, before effects.
This is synthetic supplied-evidence research, not a production memory service,
live personal-memory inspection, Voyage comparison or plan/build execution.

Prior probes: v2 passed 58 offline checks and completed 20 native calls. Four
revised memory replies were usable; distinct evidence/decision outcomes avoided
two redundant escalations. Luna solved the calculation without stronger help.
No live reasoning rescue or confident-error detection was demonstrated.

Cases will cover new capture, conditional correction, cross-project nonduplicates,
duplicate consolidation with an exception, scoped forgetting, classification,
absent evidence, unmade choice, accepted-versus-proposed chronology, a complete
policy calculation, untrusted instruction content, and host-assigned ambiguous
forgetting. Classification here means node kind (note to lesson), not security
sensitivity. Consolidation is a proposed capability; retain both merged sources.
Use representative operation shapes from existing memory seams;
synthetic case frequencies and content are not a real workload distribution.
Private oracles and rubrics stay outside every model prompt.

Read-only source review grounded this mix in attune-ai's personal.py capture and
forget_topic, promotion.py promote, session_stash.py forget_by_prefix,
and long_term_classification.py. Ambiguous prefixes deliberately do not delete;
capture/promotion and security classification are separate operations. The
installed kinds differ between adapters; this prototype does not qualify that
mapping. memory_handlers.py labels search ungoverned: retrieved visibility must
not be treated as scope or ownership permission. No live memory content was read.

The model returns operation, disposition, proposed facts, explanation, support
IDs and any specific unresolved request. The host owns versioning, captures a
deep copy, validates current record/evidence/grants at acceptance and after audit,
and enforces allowed scopes, kinds, new IDs, removals and classification changes.
Only disposable candidate records exist. Current-store atomic commits, durable
deletion semantics, security classification and human form adapters remain
outside this prototype. Meaning and authority cannot be established by IDs alone.

One attempt per queued task: Luna/high except one explicit host assignment to
Astra/xhigh. Luna may escalate once on invalid output or needs_reasoning, carrying
original evidence. Missing evidence or a user decision stops with its request;
stale inputs stop without escalation. No repeated repair or bounce. The explicit
assignment tests enforcement of host policy, not empirical model necessity.

Preselect three actual queue outputs for a separate Astra audit of operation,
meaning, scope, explanation and disposition, including incorrect abstention.
Separately audit four hand-authored proposals: three confident errors and one
valid unresolved outcome. Give those audits identical prompts without revealing
their labels. These injected controls are not naturally occurring Luna errors;
report natural and injected detection and false alarms separately. An audit may
quarantine a proposal but never grants effects or repairs it silently.

Compare three selected tasks with direct Astra using identical worker contracts
and source evidence, counterbalancing which model runs first. Stronger necessity
is unknown unless matched evidence shows a useful difference. Do not infer
unnecessary escalation solely from a successful stronger response.

Twelve queue tasks, three matched baselines, three scheduled audits and four
injected-control audits: 22 planned calls, maximum 33 including all eleven
possible Luna escalations. Existing Codex subscription, Luna/high and Astra/xhigh,
CLI profile inherited from preserved trials. Freeze actual CLI version, all
sources, case rubrics and schedule before dispatch. Cap each call at 180 seconds
and the campaign at 1,800 seconds. Stop on native transport/protocol failure;
no automatic retry, provider fallback, new credentials or direct API charges.

Before dispatch, test new/removed/duplicate IDs, forbidden scope/kind changes,
exact no-change snapshots, stale record/evidence/grants, unresolved requests,
one-hop escalation, host assignment, audit quarantine, original-evidence handoff,
unknown native output, cap/deadline failure and frozen-ledger refusal. Source
grading is explicit unblinded lead judgment separate from structural acceptance.
Count wrong operation, missed escalation, needless escalation, incorrect requests
for human input, missed false completion and unsupported claims separately;
unknown empirical model necessity remains unknown. Report every attempted call,
token field, cache difference and process duration, with audits separately and
included. Preparation/review/grading are excluded from native-path totals and
disclosed; first visible finding and subscription dollar savings are not measured.

Rejected alternatives: another dedicated sorter call before every routine task
(adds unproven overhead); asking Luna to invent permission or version metadata;
declaring hard labels proof of stronger-model need; grading only response shape;
pretending injected audit errors arose naturally; changing prior frozen trials.
